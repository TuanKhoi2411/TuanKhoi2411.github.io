# Portfolio Assets

Static files used by the Nguyen Tuan Khoi finance portfolio.

## Structure

```text
assets/
├── brand/
│   └── favicon.svg
├── social/
│   └── portfolio-share.png
└── cases/
    ├── fpa/
    ├── finance-bi/
    └── fpt/
```

- `brand/` contains reusable identity files.
- `social/` contains the Open Graph image used when the portfolio is shared.
- `cases/` contains visual evidence grouped by the case study that uses it.

Keep generated stylesheets and font bundles separate from these authored portfolio assets.
