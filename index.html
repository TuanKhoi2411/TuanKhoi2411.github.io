HOW I WORK

From messy inputs to an answer people can defend.

My work sits between finance fundamentals and modern analytics. The aim is not maximum complexity; it is a controlled path from source to decision.

  1. 01

    Frame the decision

    Define the question, owner, time horizon, and action before opening the tool.

  2. 02

    Build the evidence chain

    Document sources, cleaning rules, assumptions, and reconciliation checks.

  3. 03

    Make trade-offs visible

    Use scenarios, sensitivity, and error metrics so uncertainty is never hidden.

  4. 04

    Land the recommendation

    Translate the output into what to do, what to monitor, and what could change the view.
